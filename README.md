# Список покупок по блюду

Минимальный интерфейс Streamlit: пользователь указывает блюдо, число порций и формат ответа, приложение запрашивает DeepSeek и показывает список покупок.

## Требования

- Python 3.10+
- ключ DeepSeek API в переменных окружения (см. [документацию DeepSeek](https://api-docs.deepseek.com/))

> [!WARNING]
> С GigaChat возникли проблемы(а ключ дипсик уже был).

## Установка и запуск

```bash
python -m venv .venv
```

Windows (PowerShell):

```powershell
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
Copy-Item .env.example .env
```

Linux / macOS:

```bash
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
```

Заполните в `.env` как минимум `LLM_PROVIDER=deepseek` и `LLM_API_KEY`. Секреты в код не записывайте.

```bash
streamlit run streamlit_app.py
```

Откроется локальная страница интерфейса (обычно http://localhost:8501).

## Проверки сценария «ввод → ответ»

Порог длины ввода — 500 символов (после обрезки пробелов). Пустой и слишком длинный текст **не отправляются** в API.

1. **Нормальный текст.** В поле «Что приготовить» введите `борщ`, выберите `2` человека и любой формат, нажмите «Сгенерировать список покупок». Ожидание: список продуктов (по строке на продукт). Для формата «Список + шаги» ниже списка должны появиться 5–8 коротких шагов приготовления.

2. **Пустой текст.** Очистите поле блюда и нажмите кнопку. Ожидание: сообщение «Напишите, что хотите приготовить.» Вызова DeepSeek нет.

3. **Слишком длинный текст.** Вставьте в поле более 500 символов (например, повторите фразу много раз) и нажмите кнопку. Ожидание: «Слишком длинный текст — сократите или разбейте на части.» Вызова DeepSeek нет.

## Как воспроизвести ошибку доступа

1. В `.env` удалите значение `LLM_API_KEY` (оставьте переменную пустой) или временно переименуйте файл `.env`.
2. Перезапустите приложение.
3. Введите обычное блюдо (`борщ`) и нажмите кнопку.

Ожидание: «Не настроен доступ к сервису.» Traceback в интерфейсе не показывается.

Другие сообщения API (без сырых исключений на экране):

- сервис 5xx — «Сервис временно недоступен. Попробуйте позже.»
- таймаут или сеть — «Не удалось получить ответ. Попробуйте ещё раз.»
- пустой или битый ответ модели — «Пустой ответ модели. Попробуйте переформулировать вопрос.»
